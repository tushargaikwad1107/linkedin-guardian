# Workflows

Sanitized n8n exports. Credentials, Google IDs and keys are removed; replace every `YOUR_GOOGLE_ID` with your own.

| File | Workflow |
|---|---|
| 01_error_alerter.json | Error Alerter |
| 02_voice_drafter.json | Voice Drafter |
| 03_brain.json | Brain chat agent |
| 04_job_intake.json | Job Intake |
| 05_job_matcher.json | Job Matcher |
| 06_connection_assistant.json | Connection Assistant |
| 07_publisher.json | Publisher with images |
| 08_content_studio.json | Content Studio |
| 09_engagement_scout.json | Engagement Scout |

Import each into a **new, empty** workflow so node names stay exact.

Personal details are replaced with `<placeholders>` and `YOUR_...` values. Fill in your own before running.
